# StatSkill AI

The complete application is in [`SIH/`](SIH/README.md).

## Contributor quick start

```powershell
cd SIH
.\setup.ps1
.\run.ps1
```

Open http://127.0.0.1:8000 after the server starts. Setup installs the Python
dependencies, prepares the clean RAG database and study corpus, and downloads
the required local Ollama models without an API key.
